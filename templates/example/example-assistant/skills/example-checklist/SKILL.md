# Example Checklist

EXAMPLE. This skill shows the skill folder layout. It turns one short request into a three-item checklist. It is a sample, and it does not record a real workflow used by Dex Copeland.

## Instructions

1. If the user did not name a topic, ask for one topic and stop.
2. Read [references/format.md](references/format.md) in this folder.
3. Reply with exactly three checklist lines in that format, and no other sections.
4. Use the user's words for the topic. Do not add research, tools, or extra steps.

## Limits

Stay inside the request. If the user asks for something other than a checklist, say that this sample only writes a three-item checklist.
